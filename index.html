Google Calendar setup

One-time setup for this extension:

  1. Enable Google Calendar API in your Google Cloud project.
  2. Configure Google Auth consent and add your account as a test user if required.
  3. Create an OAuth client of type Chrome Extension using this extension’s ID: available after loading in Chrome
  4. In the project folder, run:node configure-calendar.cjs YOUR_CLIENT_ID.apps.googleusercontent.com
  5. Reload the extension in chrome://extensions, open a new tab, and connect.

Full instructions are in CALENDAR_SETUP.md. No client secret is needed.
